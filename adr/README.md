# Architecture decision records

One file per decision, numbered, one page each: `0001-why-redpanda-over-kafka.md`. The format is Michael Nygard's:

```
# 0001. Why Redpanda instead of a Kafka cluster

Date: 2026-11-03
Status: accepted

## Context
What forced the decision: the constraint, the volume, the laptop.

## Decision
What you chose, in one sentence, then how.

## Consequences
What becomes easier, what becomes harder, what you would revisit at 100x.
```

The portfolio reads the titles of this folder as your decision records.
